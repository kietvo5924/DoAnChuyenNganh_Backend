# Planmate: AI-Powered Task Management API 

A smart task management API that leverages Artificial Intelligence to help users organize, schedule, and optimize their daily routines efficiently.

##  Key Features
- **AI Integration:** Integrates seamlessly with OpenAI via **Spring AI** to auto-generate tasks, suggest optimized schedules, and provide smart productivity recommendations.
- **Cloud Media Storage:** Handles secure upload and management of user assets (images/files) using the **Cloudinary API**.
- **Automated API Documentation:** Provides an interactive and comprehensive UI for testing API endpoints using **Springdoc OpenAPI (Swagger 3.0)**.
- **Secure Access:** Protects user data and task schedules with robust JWT-based authentication.

##  Tech Stack
- **Framework:** Java 17, Spring Boot 3
- **Artificial Intelligence:** Spring AI (OpenAI integration)
- **Cloud Storage:** Cloudinary API
- **API Documentation:** Swagger UI / OpenAPI 3.0
- **Database:** PostgreSQL
- **Security:** Spring Security, JWT
